# 盐阜潮涌 · 盐城80后人生志

在盐城的时代与地方记忆里，走过一位80后的半生。出生年份为1980—1989年，当前故事止于2026年。

童年的街巷、游戏、同学和家乡味道，是这款游戏的情绪底色。成年后，玩家在家庭条件、技能、资金和健康的约束中，为自己的生活作决定。选择会留下工龄、账本、关系和后续事件，也可能在中途被新的处境打断。

## v0.3 的生活节奏

工作后，年度重心三年一选，每年仍有具体生活选择。爱人、双方父母、孩子、运动、工作与房车会持续影响后面；触及健康、关系和资金门槛时提前进入转折。结局不再展示逐年账本。

大学增加985类、211类与普通本科的综合准备门槛；重要节点可重选，真实重算后通过走马灯呈现变化。叙事朝安静、克制的白描调整，保留童年回忆。

## 本地运行

建议 Python 3.10+。服务代码兼容现有 Python 3.8 环境，生产运行只使用 Python 标准库。

```sh
python server.py
```

打开 `http://127.0.0.1:8766/`。数据库默认写入 `data/lives.sqlite3`，不进入 Git。只阅读游戏也可以直接打开 `index.html`；公开发布功能需要服务器。

## 修改和检查

前端为原生 HTML/JavaScript，样式文件已经生成并随源码保存。修改 Tailwind 类名后重新构建：

```sh
npm ci
npm run build:css
npm test
python -m unittest discover -s tests -p "test_*.py"
```

`npm test` 包含数值模型、剧情分流、盐都1986年男性100局、跨年份200局和100个不同角色的模拟。模拟使用真实游戏处理函数和最小DOM；它不等同于数百次人工浏览器体验。详细记录自动写入 `tests/reports/`，不上传玩家记录。

## 内容与发布边界

人物和人生情节为虚构，收入、房价、费用、成功概率均为游戏平衡参数，不是官方统计、人生预测或现实投资建议。旧地方历史素材尚未逐条核实，不能作为史料使用。健康是体力与负担指数，当前版本不模拟死亡；2026年结卷是半生回顾。

公开长卷没有账号系统。发布凭证保留在发布时的浏览器，只有持有凭证者可以撤下该页；清除网站数据会失去这一入口。本地收藏与公开发布分别保存。服务器仅接受有限长度的文字记录，不提供附件、真实履历或任意HTML发布功能。

本仓库包含游戏源码、设计说明和测试，不包含运行数据库、凭证、本地收藏和旧稿备份。暂未指定开源许可证。
