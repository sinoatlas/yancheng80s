# 2026-11-20 玩法深化实施计划

目标：落实用户接受的收入支出、职业成长、多维人生回顾三个方向，保留盐城80后到2026年的定位。用户已授权按建议直接实施。

技术：原生HTML/JavaScript，保留页面，将可测试的数值模型放入 life-model.js，无前端生产依赖；为用户后续要求的公开人生页增加Python标准库服务与SQLite。经济参数是平衡用的游戏设定，不宣称官方统计。既有史料待考状态保留。

- [x] 年度模型：18岁起年度重心；每自然年仅结算一次，账本展示期初现金、劳动收入、生活/教育/租住/房贷/利息支出、事件变化、期末现金。负现金明确为周转欠款。
- [x] 职业成长：分行业经验、专业技能、学历加成、阶段提升；就业才计工作年限；转行不抹去履历，留岗继续积累。复读延后毕业并保留在读状态。
- [x] 住房投资：现金门槛、一次性家庭支持、房产价值及贷款分开；20年等额年付房贷；租房有费用。投资不可无本金凭空获利。
- [x] 人生回顾：教育、职业时间线、家庭陪伴、健康、现金和房贷分列；只使用本局记录，治疗选择不评判孝顺高低。
- [x] UI：年度选择、年度账本、成长进度、结局回顾；中文移动端和浏览器实际交互检查。
- [x] 验证：数值守恒/贷款到期/年度幂等/在读学生/转行经验/随机种子/状态重置；200局固定种子全流程及1986盐都路线对照；独立最终代码审查。

边界：不增加完整婚育模拟；不将幻想回望伪装成第二人生。旧历史库不在本轮逐条考证。初始项目非Git目录，保留本地备份，并新建GitHub仓库交接。
