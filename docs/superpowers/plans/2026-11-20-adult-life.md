# 成年生活体系深化

用户指出职业之后的家庭、健康选择缺少可感知效果，要求完善爱人、双方父母、单身、子女、运动、工作、房车，并收起完整账本。沿用用户授权的自主实施方向。

## 架构与边界

- 新增独立 `adult-life.js`，保存具体关系人物、子女阶段、压力与运动习惯、照护安排、车辆及持续作用；不增加生产依赖，不变更公开数据库结构。
- `life-model.js` 继续负责唯一年度结算与资金守恒，接收成年体系的收入/支出/生活反馈。
- 控制器负责状态驱动事件、生活安排菜单与反馈展示。早年回忆保留；婚育与置业可选择，不以单身为失败。
- 现实医疗、教育与经济参数不作预测，保留虚构说明；本轮不模拟死亡、完整法律/财产分割或职业资格制度。

## 实施与验收

- [x] 相识/交往/结婚/分开状态，未婚与单身具有有效生活选项；夫妻关系影响日常情绪与事件，家庭收入按实际状态结算。
- [x] 双方父母分别有年龄、状态、关系与照护安排；照护不等于一次加分。
- [x] 自主选择养育，子女随年份成长，支出与陪伴、阶段事件持续发生；未育路线完整。
- [x] 压力、运动习惯、恢复期影响后续健康与工作能力，低健康不能无代价继续满负荷。
- [x] 后续再购房、买车/卖车，贷款和持有费用可追溯，通勤和探亲有生活作用。
- [x] 工作场景依职业与生活责任变化；近年生活变化与因果回响可见，完整账本默认折叠。
- [x] 关系与义务状态测试，100盐都/200跨年/100角色回归，浏览器桌面/手机实际流程，新增部分独立审查。
