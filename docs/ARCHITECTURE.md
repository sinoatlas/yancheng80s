# 当前实现说明

## 文件与职责

- `index.html`：已有地域/家庭/童年素材与 GameController，负责事件排序、选项门槛、人生记录、界面和本地收藏。
- `adult-life.js`：伴侣、父母/姻亲、子女、压力、运动、车辆、时代冲击、三年回响与状态事件；只返回年度收入调整和费用，现金仍由主模型一次结算。
- `life-model.js`：年度收支、技能与分行业工龄、住房贷款、随机数、多年计划和多维总结；浏览器与 Node 共用。
- `public-client.js`：自愿发布已完成人生，保存撤下凭证；只发送公开页面需要的字段。
- `gallery.html`：公共列表与一人一页，服务端文字用 textContent 渲染。
- `server.py`：Python 标准库 HTTP 服务和 SQLite；仅监听本机回环，由 HTTPS 反向代理对外提供服务。
- `styles.css`：已编译的 Tailwind 样式，网页无需连接外部字体或样式 CDN。

## 一年的执行顺序

进入年份 → 记录期初现金 → 就业后的三年重心（期间自动沿用） → 根据状态插入转折/计划后续 → 处理这一年的其他事件 → 年末统一结账 → 下一年。

结账对年份幂等。账本恒等式为：期末现金 = 期初现金 + 事件净变动 + 收入 − 支出。首付计入事件，房贷本息计入年度支出；净资产另外加住房和车辆估值并减各自未还本金。

进修、异地、副业和陪伴计划各有开始与到期年。到期当年仍结算，下一年展示后续。中途调整不退启动投入，停止后续年度作用。2026年仍在进行的计划明确写为“仍在继续”，不推算结卷之后的人生。

复读路线在19岁再次选择，大学毕业推迟到23岁。毕业事件必须留在相应自然年内，不能排到下一年年度重心之后。专业技能有100上限；经验按职业保留；进阶按每个职业已记录的最高等级计算，返回旧行业不重复领奖。

## 公开长卷

接口：`GET/POST api/lives`、`GET/DELETE api/lives/<id>`。列表分页每次20条。每条记录包含生成姓名、地区、出生年份、半生标题、模拟净资产、总结及逐年日志；不保存设备的其他收藏。

发布前浏览器生成随机撤下凭证并持久保存，服务端只存其 SHA-256。相同凭证重复发布返回同一页面，撤下需同源请求并匹配凭证。静态文件采用白名单，数据库、测试、文档和备份不能通过HTTP路径读取。正文长度与格式受限，单IP每小时最多10次新发布。

SQLite 使用 WAL；数据目录必须与程序目录分别备份。部署更新程序不能覆盖数据目录。当前没有账号恢复、举报与审核后台；不开放自由编辑真实履历或附件。这些限制需要在规模扩大前补齐。

## 测试范围

`npm test` 包含独立模型与剧情检查，并调用真实 GameController 运行100局盐都1986路线、200局跨年份路线和100个不同角色。模拟使用最小DOM，不代替浏览器渲染检查。Python集成测试验证发布、幂等、列表/详情、凭证隔离、撤下与静态路径白名单。

## 内容来源与边界

现行数值是游戏平衡参数，不是官方工资或房价统计。历史素材继承自原项目，未逐条考证；旧文档声称“完全基于官方实测”的说法没有证据，本版不再沿用。原稿留在本地备份，不随发布传播。

当前尚未把旧数据与控制器完整拆分，也保留了一部分被 deepOptions 覆盖的旧选项模板。优先稳定实际行为，后续可在回归测试保护下整理。职业尚未细分岗位；具名家庭关系已接入，住房可在后续重新考虑。旧模板不会被直接视为当前实际行为。


## 重要节点回放

节点保留选择前的状态与随机数种子；日常选择记录包括菜单导航。重选后真实调用相同控制器结算，原路线仍可行时按原记录继续，条件不成立时选择可用安排。原人生与新人生分别保留，展示三年后与2026年的差异。若节点距2026不足三年，显示实际间隔。

走马灯只播放已生成的新时间线，不生成与模型无关的结论。不改选的回归用例要求整份账本一致。模拟测试使用最小DOM，动画容器另外核对实际HTML，并在浏览器中实际播放验证。

## 时代背景的边界

非典事件按2003年时的学生/就业状态呈现；2020与2022有单独选择，2021保留持续冲击。经营、企业、公共服务的收入/压力参数不同，伴侣收入和学龄孩子的安排也受影响。冲击幅度是虚构平衡参数，没有声称精确复原盐城所有行业。

核查背景所用材料：[WHO 2003年非典时间线](https://www.who.int/emergencies/disease-outbreak-news/item/2003_07_04-en)、[教育部2020年春季延期开学通知](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202001/t20200127_416672.html)。移除了旧稿将板蓝根描述为校园常规措施、将1980年代童年写成观看现代风电的表述。其他继承素材仍不作为已考证史料。
